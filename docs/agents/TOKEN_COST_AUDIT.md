## Caveat on finding #9 (model routing)

This codebase is explicitly flagged (by the user, repeatedly, across this
session) as live-money-adjacent financial infrastructure. **Model-routing
savings must never be allowed to weaken the actual reasoning quality applied
to correctness-critical code** (capital allocation, writer-lease fencing,
ledger writes, auth, RLS/tenant isolation). The safe scope for cheap-model
routing is: running/parsing deterministic tool output, formatting a report,
mechanical refactors with an obvious single correct answer, and routine
CRUD-adjacent test-writing — never the adversarial-review pass itself on
financial-critical files. `.agent/model-routing.yaml` (Phase 9) must encode
this distinction explicitly, not just by task category name.

## Not fabricated: what's genuinely unmeasured

No token-count instrumentation exists in this environment to produce exact
per-dispatch numbers, so every "token impact" column above is a directional
qualitative call (Low/Medium/High), not a measured percentage. If precise
numbers matter, the right next step is turning on usage logging (if the host
supports it) for a week of normal development and re-running this audit
against real numbers rather than estimates.
